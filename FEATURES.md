# Dotfiles - Complete Feature Guide

A cross-platform (**macOS** + **Linux**) dotfiles repo for **Fish**, **Neovim**,
**Helix**, **Alacritty**, **Ghostty**, **i3 / Sway / Waybar**, and **tmux**. Entry point is `install.sh`.

> See `readme.md` for install steps. This file documents **what each config does
> and how to use every feature**.

## 0. Install (`install.sh`)

| Command | What it does |
|---|---|
| `./install.sh` | Interactive full install (asks before each step) |
| `./install.sh --all` | Full auto, no prompts |
| `./install.sh --stow-only` | Only symlink the dotfiles into `~/.config`, skip system packages |
| `./install.sh --no-stow` | Only install system packages, skip symlinking |
| `./install.sh -h` | Help |

It is **idempotent** - safe to re-run. The flow:

1. Detect OS (macOS / Linux distro)
2. Install system packages (Homebrew on macOS; pacman / apt / dnf on Linux)
3. Clone Oh My Tmux! to `~/.tmux` and symlink `~/.tmux.conf`
4. `stow` each config dir into place
5. Install Fisher plugins
6. `nvim --headless "+Lazy! sync"` to pull nvim plugins
7. Write `~/.config/fish/conf.d/_99_dotfiles_env.fish` (proxy + fcitx env, commented out)

**Stow targets** (symlinks created):

```
fish/      -> ~/.config/fish
nvim/      -> ~/.config/nvim
helix/     -> ~/.config/helix
alacritty/ -> ~/.config/alacritty
ghostty/   -> ~/.config/ghostty
i3/        -> ~/.config/i3
sway/      -> ~/.config/sway
waybar/    -> ~/.config/waybar
tmux/      -> ~   (.tmux.conf.local)
```

**Verify after install:**

```bash
fish --version; nvim --version | head -1; hx --version; alacritty --version; ghostty +version
command -v fzf eza fd bat zoxide lazygit gh
exec fish                       # reload shell
nvim +":Lazy" +qa               # plugin status
nvim +":Mason" +qa              # LSP server status
```

## 1. Fish Shell

### 1a. `config.fish` - the core

**Login shell** (`status is-login`) sets PATH: `~/.local/bin`, `~/bin`,
`~/.cargo/bin`, plus platform-specific paths (Homebrew arm64/intel, Flutter,
Java 17, Android SDK on macOS; Linuxbrew, snap, flatpak on Linux).

**Interactive shell** (`status is-interactive`):

- **Abbreviations:** `g` -> `git`, `gst` -> `git status -sb`, `ck` -> `cd -`,
  and `?` -> `_crush_query` (macOS only - asks the Crush AI a question).
- **Aliases:** `vim`/`vi` -> `nvim`; `cat` -> `bat`; `ls`/`ll`/`la`/`tree` ->
  `eza` variants; `fd` -> `fdfind` fallback on Ubuntu.
- **Tools:** `thefuck` (alias `f`), `zoxide` (smart `cd`), `rt` (reload config).
- **Auto-ls:** every `cd` runs `eza -la --git` automatically
  (`__auto_ls_after_cd`).
- **Lazy fzf:** fzf keybindings load on first prompt (faster startup).
- **PATH extras:** `bun`, `pnpm`, Antigravity CLI, Qwen Code.

### 1b. `conf.d/` - modular auto-sourced configs

Every `*.fish` file in `conf.d/` is sourced at shell startup.

| File | Purpose |
|---|---|
| `00_os_detect.fish` | Sets `_is_macos` / `_is_linux` flags |
| `10_path_common.fish` | Common PATH for both platforms |
| `11_path_macos.fish` | macOS: Homebrew, Flutter, Java 17, Android SDK |
| `12_path_linux.fish` | Linux: Linuxbrew, snap, flatpak |
| `20_sway_linux.fish` | **Auto-starts Sway on tty1** (Linux) |
| `30_herd_macos.fish` | Herd-Lite PHP env (macOS) |
| `31_crush_macos.fish` | Ensures Homebrew bin on PATH so `crush` runs from GUI-launched shells |
| `asdf.fish` | ASDF version manager shims |
| `foundry.fish` | Foundry (Solidity) `~/.foundry/bin` |
| `rustup.fish` | Rust cargo env |
| `z.fish` | `z` directory jumper (jethrokuan/z, vendored) |
| `fzf.fish` | fzf.fish keybindings + uninstall handler |
| `keybinds.fish` | Vim-style key bindings (see 1c) |
| `claude.fish` | Adds `~/.local/bin` to PATH |
| `local.fish` | Machine-local secrets, gitignored. Template: `local.fish.example` (`PRIVATE_KEY`, `BSC_DEPLOY_SECRET_KEY`, AI tokens) |
| `_99_dotfiles_env.fish` | Generated by install.sh - proxy + fcitx env (commented) |
| `fish_frozen_key_bindings.fish` | Fish 4.3 migration shim |

**To enable a proxy**, edit `~/.config/fish/conf.d/_99_dotfiles_env.fish` and
uncomment:

```fish
set -gx http_proxy http://127.0.0.1:7897
set -gx https_proxy http://127.0.0.1:7897
set -gx all_proxy socks5://127.0.0.1:7897
```

Leader = `Space`, localleader = `\`. Colorscheme: **Catppuccin Mocha**.
Entry: `init.lua` -> `lua/config/lazy.lua`.

- **Window/popup transparency** `winblend=20 pumblend=20`.
- Neovide tweaks (cursor animation) when running in Neovide.

## 5. i3 (Linux X11)

Config in `i3/config`:

- **Mod = Alt.** Vim keys `h j k l` move focus; `Shift+hjkl` move window.
- `Alt+Enter` terminal (alacritty) - `Alt+Shift+Q` kill - `Alt+P` rofi launcher
  (drun).
- `Alt+Ctrl+H` split horizontal - `Alt+Shift+V` split vertical.
- `Alt+F` fullscreen - `Alt+S/W/E` stacking / tabbed / toggle-split -
  `Alt+Shift+Space` float toggle - `Alt+Space` focus tiling<->float.
- Workspaces `Alt+1..0`, move window `Alt+Shift+1..0`.
- `Alt+R` resize mode (hjkl to resize, Esc/Enter to exit).
- `Alt+Shift+C` reload - `Alt+Shift+R` restart - `Alt+Shift+E` exit i3.
- Volume keys via pactl; `i3status` bar at bottom.
- File-chooser dialogs float automatically (centered 800x600).
- **Gaps:** `gaps inner 8` / `gaps outer 4`, `default_border pixel 2` with
  `smart_borders on` (single window on screen = no border).

## 6. Sway (Linux Wayland)

Config in `sway/config`:

- **Mod = Alt**, vim keys `h j k l`. Same window-management model as i3 but
  Wayland.
- `Alt+Enter` alacritty - `Alt+Shift+Q` kill - `Alt+Shift+C` reload -
  `Alt+Shift+E` exit.
- `Alt+B/V` split h/v - `Alt+S/W/E` layouts - `Alt+F` fullscreen -
  `Alt+Shift+Space` float.
- **Scratchpad:** `Alt+Shift+-` send to scratchpad - `Alt+-` show.
- `Alt+R` resize mode.
- **Gaps + borders:** `gaps inner 8` / `gaps outer 4`, `default_border pixel 2`
  with `smart_borders on`; `client.*` colors are Catppuccin Mocha (mauve
  `#cba6f7` focused, surface `#313244` unfocused, red `#f38ba8` urgent);
  `Alt+Shift+G` enters a `gaps` mode (`j`/`k` or `-`/`+`
  adjust the focused workspace, `0` resets, `Esc` exits).
- `Alt+P` opens **Vicinae** launcher; `Print` = full screenshot to clipboard;
  `Alt+Shift+S` = region to clipboard; `Alt+Ctrl+S` = region to file.
- **Autostarts:** fcitx5 (input method), blueman, nm-applet, voice-type (ZAI),
  vicinae server, dunst (notifications); restarts pipewire / wireplumber /
  xdg-desktop-portal.
- `Ctrl` remapped to CapsLock (`xkb_options ctrl:nocaps`); adaptive sync + 10-bit
  color on; `DP-1` scaled 1.5x.
- Bar = **Waybar** (bottom). Android Emulator floats.

> On Linux, **tty1 auto-launches Sway** via `fish/conf.d/20_sway_linux.fish`.

## 7. Waybar

Config in `waybar/config` + `waybar/style.css`:

**Flat edge-to-edge bar**, 26px, solid `#11111b` (Mocha crust) - no gaps, no
rounded corners. Everything is monochrome; only the focused workspace and alert
states light up.

- left = `sway/mode` (peach block, only visible in `resize` / `gaps` mode) +
  `sway/workspaces` - the focused workspace renders as a bright `●`, the rest
  stay dim numbers
- center = `clock`, `Friday 15:01`; click toggles the full date, hover = calendar
- right = `battery`, `pulseaudio`, `network`, `tray` - **icon only**, the
  percentages and SSID live in the tooltips. Scroll on the volume icon to adjust,
  click to mute.

No window title on the bar. Icons are Nerd Font glyphs - the file assumes
**FiraCode Nerd Font**.

> Reload after editing: `pkill -SIGUSR2 waybar` restarts it, but Sway owns the
> process (`swaybar_command waybar`), so `swaymsg reload` / `Alt+Shift+C` is the
> reliable way to bring it back.

## 8. Tmux (Oh My Tmux!)

`install.sh` clones `gpakosz/.tmux` to `~/.tmux` and symlinks `~/.tmux.conf` ->
upstream; your local overrides live in `~/.tmux.conf.local` (stowed from
`tmux/.tmux.conf.local`).

Key customizations:

- **Prefix = `Ctrl+Cmd+B`** (stock `Ctrl+A` / `Ctrl+B` freed for apps).
  `tmux_conf_preserve_stock_bindings=false`.
- **Mouse on** (`set -g mouse on`); `prefix + m` toggles mouse.
- New panes retain current path; themed status line with battery, uptime, clock,
  hostname, username, root indicator.
- TPM plugin manager is wired up but **no plugins enabled** by default -
  uncomment `set -g @plugin '...'` lines to add (resurrect, continuum, copycat,
  cpu).
- Custom `#{weather}`, `#{online}`, `#{wan_ip_v4}` shell variables are available
  (commented examples at the bottom of `.tmux.conf.local`).
- Reload config: `prefix + r` (Oh My Tmux default) after editing
  `.tmux.conf.local`.

## 9. Helix

Stowed to `~/.config/helix` (`helix/config.toml`). A modal editor that works
out of the box - pairs well with Neovim on remote or minimal machines.

- **Theme:** `base16_transparent` - dark, keeps the terminal background
  (transparent) so the compositor wallpaper shows through. Try others at
  runtime with `:theme <Tab>`; write the winner into `theme =`.
- **Editing:** true color; buffer tabs appear only with multiple files;
  cursor line highlight; **relative line numbers** (`5j` / `3k` jumps).
- **Shell commands:** `:sh` and friends run through a **login fish** shell
  (`shell = ["fish", "-l", "-c"]`), so PATH and env match your interactive
  shell.
- **Cursor shapes:** bar (insert), block (normal), underline (select).
- **Status line:** left = mode, spinner, file name, modification indicator;
  right = git branch, diagnostics, selections, position, encoding, line
  ending. **Indent guides** are on.
- **Custom themes:** drop a `themes/*.toml` from
  [tinted-helix](https://github.com/tinted-theming/tinted-helix) into
  `helix/themes/` (or write one that `inherits` a built-in and overrides a few
  `palette` slots). The file name becomes the theme name (`:theme mytheme`).
  See `helix/themes/README.md`.

Daily keys (Helix default): selections follow the cursor; `v` select, `x`
expand line, `%` whole file, `Space` leader (file picker, grep), `:` command
mode. Docs: https://docs.helix-editor.com/configuration.html

## 12. Extending the config

- **Fish function:** drop `~/.config/fish/functions/foo.fish` (auto-available).
- **Fish config snippet:** drop `~/.config/fish/conf.d/foo.fish` (auto-sourced).
- **nvim plugin:** add `lua/plugins/foo.lua` returning a lazy spec, then
  `:Lazy sync`.
- **nvim LSP server:** add the name to the `servers` table in
  `lua/plugins/lsp.lua` (mason installs it).
- **Waybar module:** add to `waybar/config` JSON + style in `waybar/style.css`.
- **tmux plugin:** uncomment a `set -g @plugin '...'` line in
  `tmux/.tmux.conf.local`, then `prefix + I` to install via TPM.

## Security note

`fish/conf.d/local.fish` holds machine-local secrets (`PRIVATE_KEY`,
`BSC_DEPLOY_SECRET_KEY`, AI tokens). It is **gitignored**; `local.fish.example`
is the tracked template. Copy it to `local.fish` on a new machine and fill in
real values.
